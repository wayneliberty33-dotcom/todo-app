# AGENTS.md

## Project: TaskFlow

TaskFlow is a modern, responsive To-Do List web application designed to help users create, organize, track, and complete tasks.

This file contains persistent instructions for AI coding agents working on the project. Agents must read and follow these instructions before modifying the codebase.

---

# 1. Project Overview

TaskFlow is a client-side task management application.

The application allows users to:

- Create tasks
- Edit existing tasks
- Complete and reopen tasks
- Delete tasks
- Add notes to tasks
- Assign due dates
- Set task priorities
- Assign categories
- Search tasks
- Filter tasks
- View active, completed, and overdue tasks
- Clear completed tasks
- Switch between light and dark mode
- Persist tasks using browser `localStorage`
- Use keyboard shortcuts
- Use the application on desktop, tablet, and mobile devices

The primary goal is to provide a clean, professional, responsive, and easy-to-use task management experience without requiring a backend.
